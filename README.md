# Network Monitoring and Traffic Analysis Lab

## Overview

This project demonstrates practical network monitoring, packet analysis, and security assessment techniques using industry-standard cybersecurity tools. The objective was to understand network communications, analyze packet-level traffic, identify active hosts and services, assess attack surfaces, and automate traffic analysis through Python scripting.

## Tools Used

* Wireshark
* Nmap
* Python
* Scapy
* Matplotlib
* PowerShell

## Project Activities

* Network configuration analysis
* DNS, TCP, UDP, ARP, and ICMP packet analysis
* Host discovery and network reconnaissance
* Port scanning and service enumeration
* Operating system fingerprinting
* Local host attack surface assessment
* Automated packet analysis using Python
* Traffic visualization and statistical reporting

## Key Findings

* Identified active hosts within the local network
* Analyzed DNS resolution and network communication patterns
* Detected exposed services including DNS, SMB, Microsoft SQL Server, and MySQL
* Performed operating system fingerprinting on network devices
* Generated protocol statistics and communication insights through Python automation

## Skills Demonstrated

* Network Traffic Analysis
* Packet Capture and Inspection
* Network Reconnaissance
* Service Enumeration
* Attack Surface Assessment
* Python-Based Security Automation
* Data Visualization
* Cybersecurity Reporting
